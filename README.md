# StudyQuest 🎮

StudyQuest — это статическое веб-приложение для подростков, которое превращает учёбу в игру. Пользователь добавляет учебные задачи («квесты»), отмечает их выполненными и получает очки. На заработанные очки можно покупать снаряжение для героя, прокачивать его уровень и отправлять в бой против монстров.

Приложение работает полностью в браузере: без сервера, без установки, без аккаунтов и без внешних библиотек.

---

## Функции

**Учёба и очки**
- ➕ **Добавление задач** — через форму (Enter или кнопка «Добавить квест»)
- 🎯 **Выбор очков** — за задачу даётся 10, 25 или 50 очков
- ✅ **Отметка выполнения** — галочка перечёркивает задачу и начисляет очки
- 📊 **Прогресс** — полоса выполнения с эмодзи (🌱 → ⚡ → 🚀 → 🏆)
- ⭐ **Кошелёк** — доступные очки показываются в шапке
- ✕ **Удаление** — кнопка рядом с каждой задачей

**Герой и прокачка**
- 🧙 **Карточка героя** — уровень, сила и инвентарь
- ⬆️ **Прокачка уровня** — покупка нового уровня за очки (+8 к силе)
- 🎒 **Инвентарь** — купленные предметы отображаются как значки

**Магазин**
- 🛒 **6 предметов** разной цены и силы (от Кинжала до Кольца силы)
- 🔒 Купленный предмет нельзя купить второй раз

**Арена**
- ⚔️ **5 противников** по возрастанию силы (от Слизи до Дракона)
- 🏆 **Победа** — если сила героя не меньше силы противника, он побеждает и получает награду
- 💥 **Поражение** — если снаряжение слабое, бой проигран (без штрафов)
- 🔐 Противники открываются по порядку: победил одного — открылся следующий

**Общее**
- 💾 **Автосохранение** — задачи, счёт, инвентарь и прогресс боя хранятся в `localStorage`
- 🌙 **Тёмная тема** — современное оформление, адаптивность под ноутбук и телефон
- ♿ **Доступность** — подписи для кнопок, навигация с клавиатуры, сохранение фокуса, контрастные цвета
- ✨ **Анимации** — появление карточек, пульс счёта, «плавающий» герой

## Как запустить

1. Открой папку проекта.
2. Дважды кликни по файлу `index.html` — он откроется в браузере.
3. Готово! Сервер и установка не нужны.

> Подходит любой современный браузер: Chrome, Edge, Firefox, Safari.

## Игровая экономика

- **Очки** — общая валюта. Начисляются за выполненные задачи и за победы на арене.
- **Кошелёк** (в шапке) = всего заработано − потрачено. Покупки уменьшают его.
- **Сила героя** = 10 (база) + 8 за каждый уровень + сила всех предметов.

| Предмет | Цена | +Сила |
|---------|------|-------|
| 🗡️ Кинжал | 20 ⭐ | +5 |
| 🛡️ Щит | 35 ⭐ | +8 |
| 🪄 Посох | 55 ⭐ | +12 |
| 🥋 Доспех | 70 ⭐ | +15 |
| ⚔️ Двуручный меч | 90 ⭐ | +18 |
| 💍 Кольцо силы | 110 ⭐ | +20 |

Прокачка уровня: **40 × текущий уровень** (максимум 5 уровень).

| Противник | Сила | Награда |
|-----------|------|---------|
| 🟢 Слизь | 15 | 20 ⭐ |
| 🐀 Гигантская крыса | 25 | 30 ⭐ |
| 👺 Гоблин | 40 | 50 ⭐ |
| 🗿 Каменный голем | 60 | 80 ⭐ |
| 🐉 Дракон | 95 | 200 ⭐ |

Максимальная сила героя (5 уровень + все предметы) = **120** — этого хватает, чтобы победить всех.

## Хранение данных

Задачи и игровой прогресс сохраняются в `localStorage` браузера.

- Данные пишутся в ключ `studyquest-data` в формате `{ version, spent, level, inventory, defeated, tasks }`
- При каждом запуске приложение загружает данные и сразу рисует их на экране
- Очки и кошелёк **не хранятся отдельно**, а считаются из задач, побед и потраченного — поэтому не могут «разъехаться»
- Если данных ещё нет — открывается пустой список и игра с нуля
- Если данные повреждены — они аккуратно отбрасываются, приложение не падает
- Старый формат (ключ `studyquest-tasks`) автоматически переносится в новый
- Очистить всё можно в настройках браузера: «Данные сайтов → Удалить»

## Ограничения

- **Данные хранятся только в текущем браузере.** В другом браузере или на другом устройстве прогресс будет пустым; синхронизации нет.
- **Очистка данных браузера удалит прогресс.** Режим инкогнито не сохраняет после закрытия.
- **Нет сервера и аккаунтов** — по задумке приложение полностью автономное.
- **Бой без случайности** — исход определяется только сравнением силы героя и противника (победа, если сила героя ≥ силы врага).
- **Бой без штрафов** — проигрыш ничего не отнимает, только не даёт награду.
- **Награда за противника даётся один раз**, поэтому бесконечно фармить очки нельзя.
- **Покупки необратимы** — продать предмет или вернуть очки нельзя.
- **Если снять галочку с выполненной задачи после покупок**, кошелёк может уменьшиться, но не уйдёт в минус (минимум 0).
- **Предметы и противники заданы в коде** (`ITEMS` и `ENEMIES` в `app.js`) — свои добавить нельзя без правки файла.
- **Максимальный уровень — 5**, максимальная сила — 120.
- **Автотесты отсутствуют** — проверка выполняется вручную по сценарию выше.
